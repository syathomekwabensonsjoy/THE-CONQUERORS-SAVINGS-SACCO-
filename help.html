APP USER GUIDE

Save Together, Grow Together

1. Introduction

The Conquerors Savings SACCO App is a digital platform designed to help members save money, track transactions, and manage financial records easily. The system allows both members and administrators to access savings information, monitor balances, and generate receipts for transactions.

2. Accessing the App

  1. Open the application.
  2. On the home screen, read the introduction and click Continue.
  3. Choose one of the following options:
    • User Login – for SACCO members.
    • Create Account – to register as a new member.
    • Admin Login – for administrators managing the system.

3. Creating an Account

  1. Click Create Account.
  2. Enter:
    • Username
    • Phone number
    • PIN
    • Confirm PIN
    • Security answer
  3. Accept the terms and conditions.
  4. Click Create Account.

Your account will now be created.

4. Member Login

  1. Select User Login.
  2. Enter your Username and PIN.
  3. Click Login.

After logging in, you will be able to view the dashboard and your savings information.

5. Admin Login

  1. Select Admin Login.
  2. Enter the Admin Password.
  3. Click Login.

The administrator has permission to:

  • Add new members
  • Record deposits
  • Record withdrawals
  • Edit member profiles
  • Manage transactions

6. Dashboard

The dashboard displays:

  • Total SACCO savings
  • Graph showing member savings
  • Navigation buttons for accessing member records

This section helps monitor the financial performance of the SACCO.

7. Adding Members (Admin Only)

  1. Go to Members.
  2. Enter:
    • Member name
    • Phone number
    • Member photo
  3. Click Add Member.

The member will be added to the system.

8. Deposits

  1. Open a member profile.
  2. Enter the amount in the Amount field.
  3. Click Deposit.

The member's balance will increase automatically.

9. Withdrawals

  1. Open the member profile.
  2. Enter the withdrawal amount.
  3. Click Withdraw.

The system checks the available balance before completing the transaction.

10. Transaction History

Each member profile shows a Transaction History table including:

  • Date
  • Transaction type
  • Amount
  • Balance after transaction

This allows transparent tracking of all savings activities.

11. Downloading Receipts

Members can download a transaction receipt for any transaction.

The receipt includes:

  • SACCO name
  • Receipt number
  • Member name
  • Transaction type
  • Amount
  • Balance
  • Date of transaction

The receipt is downloaded as a PDF document.

12. Contact Member

The system provides quick communication options:

  • Call button – calls the member directly.
  • WhatsApp button – opens a WhatsApp chat with the member.

13. Mobile Money Deposits

Members can send savings using Mobile Money to the official SACCO number displayed on the home page.

14. Security

  • Each member uses a PIN for login.
  • Only administrators can modify transactions.
  • Members can only view their records and download receipts.
